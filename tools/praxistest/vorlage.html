Gesamteindruck und Verbesserungswünsche

Für eine Fehlermeldung helfen: Schrittnummer, Dateikenncode, genaue Anzeige, Wiederholbarkeit und ob das Original erhalten blieb. Ein bereinigtes Bildschirmfoto könnt ihr zusätzlich zurückgeben.

„Neuer Durchlauf“ lädt zuerst das bisherige JSON herunter und beginnt danach einen leeren Bogen. Beim Zurückgeben genügt die ausgefüllte HTML oder das JSON; beide enthalten dieselben Antworten. HTML anschließend erneut öffnen und die gespeicherten Antworten kontrollieren.

Es wird nichts automatisch verschickt. Antworten bleiben in diesem Browser, soweit dessen Speicher verfügbar ist. Eine heruntergeladene Ergebnisdatei ist eure verlässliche Kopie. Die ursprüngliche HTML-Datei auf der Platte wird beim Ankreuzen nicht automatisch überschrieben.
