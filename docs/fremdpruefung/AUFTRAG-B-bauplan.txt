AUFTRAG (bitte vollständig ausführen, keine Rückfragen)

Entwirf einen Bauplan für einen Agenten, der Buchhaltungsbelege eines kleinen deutschen
Betriebs (SKR03) einem Konto zuordnet. Der Agent wird später von einem anderen
KI-System ausgeführt; du sollst das Vorgehen unabhängig entwerfen, so wie du es für
richtig hältst – nicht so, wie es üblich oder erwartet ist.

Gegeben: Belege als Text (Kassenbons, Rechnungen, Abrechnungen, Bescheide, Eigenbelege;
mit Tippfehlern aus der Texterkennung), der Name des eigenen Betriebs und die Kontenliste
unten. Es gibt keine Beispiele mit Lösung.

Liefere als Datei BAUPLAN.md (oder als Antworttext):
1. Die Schritte des Agenten in fester Reihenfolge (was prüft er zuerst, was danach).
2. Für jeden Schritt: worauf er im Beleg achtet und was er daraus schließt.
3. Regeln für Zweifelsfälle und Verwechslungen, die du für wahrscheinlich hältst.
4. Wann der Agent "unsicher" melden soll, statt zu raten.
5. Das Ausgabeformat je Beleg (Konto, Einnahme/Ausgabe, sicher ja/nein, kurzer Grund).
6. Eine Liste von Fehlern, die ein solcher Agent typischerweise macht, und wie dein
   Bauplan sie vermeidet.

Schreibe den Bauplan so, dass ein anderes System ihn ohne Rückfrage ausführen kann.
Höchstens zwei Seiten.
